How to use

  1. Draw walls by clicking or dragging across the grid. Switch to Weight to paint heavy cells that cost 5 to cross.
  2. Move the start or target by dragging them. After a run, moving them updates the path instantly.
  3. Pick an algorithm and press Visualize to watch it explore.
  4. Compare all runs every algorithm on the same grid and ranks them.

Keyboard: Space visualize · C clear path · R reset · 1–3 switch draw tool
